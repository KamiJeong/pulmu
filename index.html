Install Pulmu Read the setup guide
01 / QUICK START

Bring the smithy into Codex.

Clone Pulmu and run its installer. The skill and specialist agent definitions are copied into your Codex configuration.

Prerequisites: Git, Bash, Python 3.10+, and Codex CLI.

git clone https://github.com/KamiJeong/pulmu.git && cd pulmu && ./install.sh

Restart Codex, open a repository, then run $pulmu "Your task". For updates, configuration, and uninstall steps, read the setup guide.

02 / THE WORKFLOW

Visible stages. One orchestrated run.

Pulmu keeps the work legible without making you manage seven separate commands. The forge moves from context to implementation, verification, review, and delivery as one coherent process.

01

Inspect before impact

The forge reads the repository, finds its conventions, and shapes a focused change before implementation begins.

02

One steady hammer

A single Smith owns task files while independent specialists explore, design, diagnose, and review.

03

Proof before delivery

Verification must pass and important review findings must be resolved before Pulmu creates the final commit.

03 / THE OUTCOME

A calmer path from intent to reviewed code.

Use the default path for a local reviewed commit. When the repository and GitHub access are ready, the same workflow can prepare the pull request without changing the seven-stage vocabulary.

  • ✓ Stage progress stays visible from Ignite through Ship.
  • ✓ Existing work is preserved and force-push is off limits.
  • ✓ Local delivery remains a complete, supported outcome.
