# Security Policy

## Supported versions

Security fixes are developed for the current `main` branch and, when releases are tagged, the latest tagged release. Older snapshots may not receive backports.

## Report a vulnerability privately

Please use GitHub's private **Report a vulnerability** form in [Pulmu Security Advisories](https://github.com/KamiJeong/pulmu/security/advisories/new). Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or log.

Include enough information to reproduce and assess the report:

- the affected Pulmu version or commit
- operating system, shell version, and Codex CLI version
- affected scripts or workflow stage
- minimal reproduction steps or a proof of concept
- expected and observed impact
- suggested mitigation, if known

Remove access tokens, credentials, repository secrets, and unrelated private data. The maintainer will acknowledge the report as soon as practical, coordinate validation and remediation privately, and credit the reporter when requested and appropriate.
